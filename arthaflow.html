Account and cloud sync
Backup and data storage

By default your data is saved only in this browser (localStorage). It isn’t encrypted or backed up, and clearing browser data erases it. If you log in under “Account and cloud sync”, a copy is also kept on that account’s server. Avoid shared computers. Use “Show backup” to generate a copyable text backup, then save it somewhere safe. Backups are manual.
